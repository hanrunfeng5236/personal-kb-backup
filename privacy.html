Privacy policy

Effective 25 October 2026. This policy describes Personal KB Backup, a local, personal-use backup utility, and this public information website.

Data used and purpose

The utility processes the owner's selected knowledge-base documents, file names, and file metadata only to create, update, manage, download, and verify backups in the owner's Google Drive. It uses the Google Drive drive.file scope, limited to files created by this application or explicitly made available to it by the user.

Where data is stored

rclone runs on the owner's Windows computer. Backup data is transferred directly between that computer and the owner's Google Drive. OAuth tokens are kept in a restricted local configuration directory. Tokens and backup contents are not uploaded to this website or its source repository.

No advertising, analytics, or sale of data

The utility does not use backup contents for analytics, advertising, or model training. It does not sell or share those contents with other people or unrelated services. Google processes files as the selected storage provider under its own privacy policy.

Retention and user control

Backups remain in the owner's Google Drive until the owner removes them or uses their configured backup-management rules. The owner can revoke the application's access in Google Account connections at any time and can delete backed-up files directly in Google Drive. Revoking access stops future authorized access; it does not itself delete existing backups. Local authorization can also be removed from the owner's rclone configuration.

This public website

This site has no upload forms, tracking scripts, analytics, advertisements, or application cookies. It is hosted on GitHub Pages. GitHub may process normal hosting and security logs, including request information, under the GitHub Privacy Statement. The website is not a storage location for backups.
