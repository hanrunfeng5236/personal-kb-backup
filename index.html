Personal KB Backup

个人知识库备份 · A personal backup utility that runs locally on Windows.

What it does

The utility uses rclone to back up the owner's personal knowledge-base documents to the owner's Google Drive and to verify backed-up files. It is for the owner's own use, not a public backup service.

Google Drive access

Google authorization uses the drive.file scope. Access is limited to files created by this application or explicitly made available to it by the user. Authorization is used for backup, file management, and verification.

Your data stays out of this website

This website contains public information only. It has no sign-in, upload form, analytics, advertising, or application credentials. Backup contents are not published here.

Read the privacy policy for data handling and access controls, and the terms of use for this personal utility.
